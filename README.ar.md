**وصلة** — سوق توصيل بوجهين للأردن (ومصر).

العميل ينشر توصيل من نقطة إلى نقطة. السائقون القريبون يستلمون الطلب، يكملونه بمسح QR، ويُقيَّمون. التشغيل من لوحة تحكم ويب. مندوبو المبيعات يوسّعون الشبكة برموز إحالة.

<br>

## نظرة عامة

وصلة تربط من يحتاج توصيل بسائقين قريبين. مخصّصة لنقل الطرود والتوصيل من نقطة لنقطة — وليست تطبيق طلب طعام فقط.

**الأدوار**

| الدور | ماذا يفعل |
|------|-----------|
| **العميل** | تاجر أو فرد — ينشئ توصيلاً فردياً أو مجمّعاً، يتابع الحالة، يؤكد الاستلام، يعرض QR عند التسليم |
| **السائق** | يتصل بالإنترنت، يقبل الطلبات المناسبة، يمسح QR للإتمام، ويكسب من رسوم التوصيل |
| **المندوب** | يُنشأ من لوحة التحكم — يشارك رمز إحالة ويكسب عمولة على السائقين والتجار المحالين |
| **المشرف** | لوحة ويب — اعتماد السائقين، الطلبات، التسعير، العمولات، وإعدادات المنصة |

## أبرز المزايا

### الجوال (عميل وسائق)

- واجهة كاملة **عربي / إنجليزي** (خط Cairo ودعم RTL)
- تسجيل عبر **Google** أو البريد وكلمة المرور مع تحقق البريد و**OTP بالرسائل**
- حساب حسب الدولة (**الأردن** / **مصر**) وعملة العرض
- تحديد الاستلام والتسليم عبر الخريطة أو الموقع الحالي أو لصق **رابط Google Maps**
- معاينة المسار والمسافة والوقت المتوقع
- التوقيت: عاجل / لاحقاً اليوم / خلال يومين (مع رسوم إضافية قابلة للضبط)
- **توصيل مجمّع**: استلام واحد وحتى 10 تسليمات وسائق واحد للدفعة
- معاينة الرسوم قبل التأكيد (حسب المسافة أو منطقة عمّان الثابتة)
- دورة حياة الطلب: قبول/رفض السائق، تحرير، إلغاء، وتقييم
- **إتمام بـ QR** — العميل يعرض الرمز والسائق يمسحه
- تغذية السائق حسب نوع المركبة ونطاق التوزيع
- إحصاءات إنفاق / أرباح (اليوم · الأسبوع · الشهر · الكل)
- إدخال رمز إحالة مرة واحدة لكل عميل أو سائق
- مفتاح إيقاف عن بُعد للصيانة أو الطوارئ

### المندوبون

- لوحة إحالات (سائقون وتجار)
- رمز إحالة شخصي للمشاركة
- ملخص عمولة الفترة الحالية

### لوحة المشرف (عربي RTL)

- نظرة عامة: طلبات، إيرادات، معدل الإكمال، تنبيهات تحتاج إجراء
- اعتماد / سحب اعتماد السائقين؛ تفعيل / تعليق العملاء
- أرباح السائق وعمولة التاجر (تعليم كمدفوع + إيصالات)
- إنشاء وإدارة المندوبين وفك ربط الإحالات
- التسعير: حسب المسافة أو منطقة عمّان الكبرى + التوقيت + خصم التسليمات الإضافية
- نطاق التوزيع وقواعد حجب بعد تقييم نجمة واحدة
- أرقام الدعم وواتساب المطوّر المستخدمة داخل التطبيق

---

## كيف يعمل التوصيل؟

1. العميل ينشئ الطلب (خريطة + تفاصيل + مركبة + توقيت)
2. السائقون القريبون المناسبون يرونه ويقبلونه
3. العميل يقبل (أو يرفض) السائق
4. السائق يستلم؛ العميل يؤكد الاستلام
5. عند التسليم يمسح السائق **رمز QR** للعميل
6. تكتمل الرحلة ويقيّم العميل السائق

## لمحة تقنية

| الطبقة | التقنيات |
|--------|----------|
| الجوال | Flutter · `hooks_riverpod` · `go_router` · Cairo · عربي \| إنجليزي |
| الخلفية | Firebase Auth · Firestore · Storage · Cloud Functions · FCM |
| الخرائط | Google Maps / Places / Routes · لصق رابط خرائط ← إحداثيات |
| المشرف | Next.js · لوحة عربية RTL |
| البنية | Feature-first تحت `lib/features/*` + مشترك `lib/core/*` |

إنشاء / تحديث / إلغاء الطلبات وقبول الدفعات عبر **Cloud Functions قابلة للاستدعاء** (لقطات الرسوم من الخادم). العملاء لا يكتبون مستندات الطلب مباشرة.

## الثقة والأمان

- تحقق الهاتف ورفع وثائق الهوية
- السائق يعمل فقط بعد **موافقة المشرف**
- إتمام عبر QR
- تقييم بعد الرحلات المكتملة
- خيار إخفاء طلبات عميل مستقبلية عن سائق بعد تقييم ★١
- تعليق وصول العميل مع مسار دعم داخل التطبيق
